# Identidad visual

Esta carpeta contiene recursos visuales reemplazables. Para usar el logo definitivo:

1. Copiar aquí un archivo SVG, PNG o JPG.
2. Cambiar únicamente `logo_path` en `config/brand.json`.
3. Reiniciar Streamlit.

No es necesario modificar `app.py` ni los módulos de negocio. La paleta, textos de
marca y tipografía también se cambian en `config/brand.json`. Los colores nativos
de los controles de Streamlit se ajustan en `.streamlit/config.toml`.
